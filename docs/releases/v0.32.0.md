# HotClip v0.32.0 — correções de issues e escolha de modelo

## Correções na pré-visualização da mesa de revisão

- Quando vários vídeos consomem o mesmo material, a imagem principal, o recorte vertical e a janela de revisão usam caminhos de mídia independentes, o que evita o buffer de mídia compartilhado do Chromium deixar a tela preta para sempre ou travar o arrasto.
- O protocolo de mídia local propaga explicitamente o erro de leitura do fluxo e libera o descritor do arquivo ao cancelar.
- Uma falha de pré-visualização mostra o diagnóstico pelo `MediaError.code` real, e não reporta mais uma leitura interrompida como formato não suportado.

## Correções no menu de escolha de modelo

- Depois de buscar a lista de modelos, um menu nativo claramente clicável aparece.
- O preenchimento à mão continua existindo, para o id de modelo que o fornecedor não devolve ou que a pessoa personaliza.
