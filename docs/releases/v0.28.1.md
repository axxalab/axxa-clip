# HotClip v0.28.1 — correções no corpo da legenda e na pré-visualização de revisão no Windows

Data de lançamento: 12/09/2026

- **Corpo da legenda dinâmica**: a faixa «pequena» do estilo de marca passou de 0,85 para 0,68; a camada de renderização e a esteira de exportação usam a mesma constante, então o que a instalação do Windows mostra bate com o vídeo que sai.
- **Pré-visualização de revisão no Windows**: quando o primeiro pedido de Range do protocolo de mídia falha, o elemento de vídeo é preservado e o botão de reprodução não fica cinza para sempre; dá para recarregar e tocar ali mesmo na mesa de revisão.
- **Resposta vazia do Qwen3/QwQ**: os pedidos a modelos de raciocínio híbrido desligam a saída de raciocínio; quando um gateway estritamente compatível recusa esse parâmetro, há um recuo automático, e tanto o array de texto quanto o formato antigo de resposta são aceitos.

Verificação: os testes de regressão do caso, a checagem de tipos, a construção de produção do Electron e a checagem de diferenças passam. Os instaladores do Windows são construídos pelo fluxo de release numa máquina nativa Windows.

# HotClip v0.28.1 — Caption size and Windows review playback fixes

Release date: 2026-09-12

- **Dynamic caption size**: the Brand Style Small tier is now 0.68 instead of 0.85. The renderer and export pipeline share one constant so the Windows installer UI matches actual output.
- **Windows review preview**: a failed first Range request no longer unmounts the video and permanently disables playback. The review pane keeps the video element and supports direct reload and retry.
- **Qwen3/QwQ empty responses**: hybrid-thinking requests disable thinking output, fall back when a strict compatible gateway rejects that parameter, and accept both text-array and legacy response shapes.

Verification: focused regressions, typechecking, the Electron production build and diff checks pass. Windows installers are built by the release workflow on a native Windows runner.
